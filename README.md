# LeetCode Solutions

A comprehensive collection of LeetCode problem solutions organized by pattern types.

## Structure

Each pattern type contains multiple problems, and each problem has its own markdown file with:
- Problem statement
- Brief explanation and challenges
- Multiple solution approaches (Brute Force, Better, Optimal)
- Code implementations in Java and C++
- Approach comparison and when to use each
